Emojinote is a note-taking iOS app for organizing notes with emoji. It is really that simple.

It started as a mobile version of [Notational Velocity](https://notational.net/), the classic Mac app that used the same input for both searching and creating notes. While using it, I started adding emoji to notes so I could tag and filter them quickly from that input. That became the whole idea: a tab bar where emoji worked as a simple filing system without tags or folders.

The app is free to download, with an in-app purchase to unlock unlimited. You can read the full story in this [guest post](https://marvelapp.com/blog/quest-find-happiest-notes-app/) for Marvel.
